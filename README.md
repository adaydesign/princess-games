# 👑 Princess Learning Kingdom — ชุดเกมเจ้าหญิงพัฒนาทักษะเด็กระดับอนุบาล (Single-File HTML Games)

ชุดเกมการศึกษาสำหรับเด็กปฐมวัย (ระดับชั้นอนุบาล อายุประมาณ 3–6 ปี) ในธีม **เจ้าหญิงเทพนิยาย** ที่พัฒนาด้วยแนวคิด **Single-File HTML Architecture** คือ **1 เกม = 1 ไฟล์ `.html`** โดยรวมโครงสร้างหน้าเว็บ (HTML), การตกแต่งและแอนิเมชัน (CSS), ตรรกะของเกม (JavaScript), ภาพประกอบทั้งหมดที่วาดด้วยโค้ด **SVG (Scalable Vector Graphics)**, เสียงบรรยายด้วย **Web Speech API** และเสียงดนตรี/เอฟเฟกต์สังเคราะห์ด้วย **Web Audio API** ไว้ภายในไฟล์เดียวอย่างสมบูรณ์ ไม่ต้องพึ่งพาไฟล์รูปภาพ ไฟล์เสียง หรือไลบรารีภายนอก และสามารถเปิดเล่นแบบออฟไลน์ได้ทันที

---

## 🌟 จุดเด่นของโปรเจค

- **ไม่พึ่งพาไฟล์ภายนอก (Zero External Assets)**: ภาพตัวละคร ปราสาท โคมลอย สร้อยไข่มุก อัญมณี และฉากหลังทั้งหมดเขียนขึ้นด้วยโค้ด `<svg>` ภายในไฟล์ ทำให้ภาพคมชัดทุกขนาดหน้าจอและไฟล์มีขนาดเบา
- **ออกแบบเพื่อเด็กอนุบาลโดยเฉพาะ (Kindergarten-First UX)**:
  - มี **เสียงบรรยายภาษาไทย (`th-TH`)** อ่านโจทย์ คำแนะนำ และคำชมเชย ช่วยให้เด็กที่ยังอ่านหนังสือไม่คล่องสามารถเล่นตามเสียงได้
  - ปุ่มกดขนาดใหญ่ กดง่ายทั้งบนหน้าจอสัมผัส (แท็บเล็ต/มือถือ) และเมาส์ พร้อมรองรับการเล่นด้วยแป้นพิมพ์
  - **เรียนรู้เชิงบวก (Positive Reinforcement)**: ตอบผิดไม่หักคะแนน มีคำใบ้ช่วยทีละขั้น (Scaffolding) และสามารถกดฟังซ้ำ/ดูซ้ำได้เสมอ
- **เข้าถึงได้ง่าย (Accessibility)**: รองรับ `aria-live`, `aria-label`, ลำดับการโฟกัสด้วยแป้นพิมพ์ และเคารพการตั้งค่าลดการเคลื่อนไหว (`prefers-reduced-motion: reduce`)

## 🧠 ทักษะพัฒนาการเด็กปฐมวัยที่ครอบคลุม

1. **ทักษะด้านสติปัญญาและคณิตศาสตร์เบื้องต้น (Cognitive & Early Math Skills)**
   - การจำแนกและต่อยอดแบบรูป (`pattern_ariel.html`)
   - ความเข้าใจความสัมพันธ์ของจำนวนที่รวมกันได้ 10 (`math1.html`, `math1_en.html`)
2. **ทักษะความจำและหน้าที่บริหารสมอง (Executive Function & Working Memory)**
   - การจดจำลำดับภาพควบคู่กับเสียงดนตรี (`lantern_rapunzel.html`)
   - การวางแผนเส้นทางและยับยั้งชั่งใจในเขาวงกต (`maze.html`)
3. **ทักษะการรับรู้ทางสายตาและมิติสัมพันธ์ (Visual Perception)**
   - การสังเกตความเหมือน–ความต่างของรายละเอียด (`find_difference1.1.html`)
   - การเชื่อมโยงรูปทรงกับเงา (`match.html`, `match_en.html`)
4. **ทักษะด้านภาษาและการฟัง (Language & Auditory Skills)**
   - การฟังคำสั่งและคำศัพท์ภาษาไทย (`th-TH`) และภาษาอังกฤษ (`en-US`) ผ่านเสียงพูดโต้ตอบตลอดการเล่น

## 🛠️ สถาปัตยกรรมทางเทคนิค (Technical Architecture)

แต่ละเกมถูกสร้างเป็นไฟล์ `.html` เดี่ยวที่ประกอบด้วย 4 ส่วนหลัก:

1. **HTML5 Semantic Markup**: ใช้แท็กที่มีความหมายชัดเจน (`<header>`, `<main>`, `<nav>`, `<section>`, `<button>`) พร้อมคุณสมบัติ `aria-live="polite"` และ `aria-label`
2. **Modern CSS3**:
   - ใช้ CSS Custom Properties (`:root`) กำหนดโทนสีตามธีมของเจ้าหญิงแต่ละองค์
   - ใช้ Responsive Grid / Flexbox และ `clamp()` เพื่อปรับขนาดตัวอักษรและปุ่มให้เหมาะกับทั้งหน้าจอมือถือ แท็บเล็ต และคอมพิวเตอร์
3. **Inline Procedural & Declarative SVG**:
   - วาดฉากหลัง ตัวละครเจ้าหญิง และวัตถุในเกมด้วย `<svg>` (`path`, `circle`, `ellipse`, `polygon`, `g`) โดยตรงในไฟล์และสร้างแบบไดนามิกผ่าน JavaScript
4. **Web Speech API + Web Audio API**:
   - `window.speechSynthesis` และ `SpeechSynthesisUtterance`: เลือกเสียงพูดภาษาไทย (`th-TH`) หรือภาษาอังกฤษ (`en-US`) อัตโนมัติ พร้อมระบบ Fallback Timer ป้องกันเกมค้างหากอุปกรณ์ไม่มีชุดเสียงพูด
   - `window.AudioContext`: สังเคราะห์เสียงโน้ตดนตรีประจำโคมลอย เสียงกระดิ่งเมื่อตอบถูก และเสียงดนตรีฉลองชัยชนะด้วยคลื่นเสียง (`sine`, `triangle`) โดยไม่ต้องโหลดไฟล์ `.mp3` หรือ `.wav`

## 🚀 วิธีการเปิดเล่น (How to Play)

### วิธีที่ 1: เปิดไฟล์โดยตรง (ง่ายที่สุด ไม่ต้องติดตั้งโปรแกรมเสริม)
1. ดับเบิลคลิกที่ไฟล์ **`index.html`** เพื่อเปิดในเว็บเบราว์เซอร์สมัยใหม่ (เช่น Google Chrome, Safari, Microsoft Edge, Firefox)
2. คลิกเลือกการ์ดเกมที่ต้องการเล่น หรือกดปุ่ม **🔊 ฟัง** บนการ์ดเพื่อฟังคำแนะนำก่อนเข้าเกม

### วิธีที่ 2: รันผ่าน Local Web Server (ทางเลือกสำหรับนักพัฒนา)
```bash
# ใช้ Python 3
python3 -m http.server 8000

# จากนั้นเปิดเบราว์เซอร์ไปที่ http://localhost:8000
```

> **คำแนะนำเรื่องเสียงพูดภาษาไทย**: หากเปิดเล่นบนอุปกรณ์พกพาหรือคอมพิวเตอร์แล้วไม่ได้ยินเสียงบรรยายภาษาไทย สามารถตรวจสอบการติดตั้งชุดเสียงพูดภาษาไทย (Thai Text-to-Speech Voice เช่น Kanya บน macOS/iOS หรือ Google Thai TTS บน Android/Chrome) ในการตั้งค่าระบบของอุปกรณ์ ทั้งนี้แม้ไม่มีเสียงพูดในเครื่อง เกมทุกเกมก็ยังมีข้อความภาษาไทยและเสียงดนตรีสังเคราะห์ให้เล่นได้ตามปกติ
